# 📚 Smart Library

A modern Library Management System built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). It enables administrators and members to efficiently manage books, transactions, and library activities through a secure and user-friendly interface.

---

## ✨ Features

- 🔐 JWT Authentication
- 👨‍💼 Admin & Member Login
- 📖 Book Management (Add, Update, Delete)
- 👥 Member Management
- 📚 Book Issue & Return
- 📅 Book Reservation
- 📊 Dashboard with Library Statistics
- 🔍 Search Books and Members
- 📱 Responsive User Interface

---

## 🛠 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- CSS

---

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/pintoomeena/Smart_library.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Create a `.env` file inside the backend folder and configure your MongoDB connection string and JWT secret.
